# CTA keyword registry

One row per reel that uses a comment keyword. The evaluator checks new keywords against
this list so two reels never promise the same word. Keywords are one word, upper case,
easy to type, and specific to the deliverable.

| Keyword | Reel | Deliverable | Date | Status |
|---|---|---|---|---|
| | | | | |

Status: `promised` (reel posted, deliverable ready) · `pending` (reel written, deliverable
not built yet) · `retired` (stop using).
