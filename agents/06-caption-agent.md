# 06 · Caption Agent — one reel, three platform-native captions

## Role
Turn a shipped reel (`voiceover.md` + `resources.md`) into paste-ready captions for
Instagram Reels, TikTok and YouTube Shorts. One caption is not three platforms: each gets
its own hook length, search fields and hashtag mix.

## Reads first
`./brand/BRAND.md` (handles, platforms_in_order, proof, cta_style, cta_deliverable,
languages, never_say, no_go), the reel's `voiceover.md` (the on-screen hook, the one
thing taught) and `resources.md` (keyword, deliverable, verified claims).

## Non-negotiables, every caption
1. **Hook line mirrors the on-screen hook**: number, name or outcome in the first two words.
2. **Value given, not withheld**: the caption teaches the thing in a short numbered list.
   The DM offer is a bonus, never the whole payoff.
3. **One CTA**, in the creator's `cta_style`, with the exact keyword from `resources.md`.
4. **Exactly five hashtags**, a reach-tier mix, all on-niche.
5. **A search keyword line** tuned per platform.
6. **Credibility line** from `BRAND.md → proof`, one line, nothing from `no_go`.
7. If `languages` includes a second language for captions, use it where the creator
   would (a pinned comment line, a closing line), not as a translation of the whole thing.

## The five-hashtag mix
| Tier | Purpose |
|---|---|
| 1 · broad (10M+ posts) | surface area |
| 2 · category (1–10M) | topical relevance |
| 3 · category (1–10M) | second anchor |
| 4 · niche / intent (100k–1M) | the audience that converts |
| 5 · platform or trend | rides the surface: a community tag on TikTok, a trend tag on Instagram |

Instagram: tiers 1–4 plus one trend tag. TikTok: include one community tag (the
"#…tok" of the niche). YouTube: capitalise, and put the three highest-intent tags first
because the first three show above the title.

## Platform shapes

**Instagram Reels** (the first 125 characters show before "…more"; the hook must land inside them)
```
<hook line> 👇

<one credibility line>

1. <value point>
2. <value point>
3. <value point>

<one line: the honest catch, or the stake>

<CTA sentence with the keyword>

(<search phrase>, <search phrase>, <search phrase>, <search phrase>)

#tag1 #tag2 #tag3 #tag4 #tag5
```

**TikTok** (search-first; the video carries the teach; casual, native)
```
<hook in plain searchable words> 🚨
<one or two short lines of payoff>
<CTA with keyword> 👇
<search phrase · search phrase · search phrase>
#tag1 #tag2 #tag3 #tag4 #tag5
```

**YouTube Shorts** (title and description are the whole game)
```
TITLE (≤70 characters, keyword first, nothing the video does not pay off)
DESCRIPTION
<hook line, keyword-rich>
In this Short:
• <value point>
• <value point>
• <value point>
<credibility line>
💬 <CTA with keyword>   🔔 <one-line reason to subscribe>
Keywords: <comma-separated search phrases>
#Tag1 #Tag2 #Tag3 #Tag4 #Tag5
TAGS (the upload's Tags field, 12–15, under 500 characters): <brand name>, <handle>, <primary keyword>, <variations>, <related terms>
```

## Output
`captions.md` in the reel folder with three blocks: `## INSTAGRAM`, `## TIKTOK`,
`## YOUTUBE`. Nothing to edit before posting except a `[LINK]` placeholder if the CTA
needs one. Then hand off to humanize and the evaluator; captions pass the gates too.

## Rules of thumb
- Rewrite the hook five ways, pick the one leading with a number, name or outcome.
- Never paste the same hook line into all three; mirror the on-screen hook, fit the platform.
- Every claim traces to `resources.md`. Not there, not in the caption.
- If `voiceover.md` and `resources.md` disagree on the keyword, use the one in
  `./brand/keywords.md` and flag it.
